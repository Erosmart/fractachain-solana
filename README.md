# Fractachain

[![Solana](https://img.shields.io/badge/Solana-9945FF?style=flat&logo=solana&logoColor=white)](https://solana.com)
[![Next.js](https://img.shields.io/badge/Next.js_14-000000?style=flat&logo=nextdotjs&logoColor=white)](https://nextjs.org)
[![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat&logo=typescript&logoColor=white)](https://www.typescriptlang.org)

El primer mercado regulado de Activos del Mundo Real (RWA) de Argentina, sobre **Solana**: licitación primaria de acciones y deuda para empresas y productores, con negociación en el mercado secundario on-chain.

- Tokens regulados con **Token-2022** (compliance nativo: cuentas congeladas hasta KYC)
- Order book on-chain con **Manifest** (CLOB, sin AMM)
- Wallets **Phantom** / Solana Wallet Standard
- `frontend/` — Next.js 14 · `backend/` — API Node · `contracts/` — programa Anchor
- Demo navegable en `/demo` (simulación client-side de todo el flujo)

Basado en Solana · devnet.
